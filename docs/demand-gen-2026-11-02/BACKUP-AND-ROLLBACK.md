# Backup and rollback (2 Nov 2026)

No backups were made by this session, because nothing was changed and the stores and Ads account were not reachable. Make these before any change in the proposals.

## Shopify themes (each store: tjifct-34 and xydmiq-em)

1. Online Store → Themes → live theme → ⋯ → **Duplicate**. Rename the copy "BACKUP 2026-11-02 before tracking fix".
2. Also ⋯ → **Download theme file**. Keep the zip on your computer, not in a public folder.
3. Make all fixes in another duplicate, left **unpublished**. Preview it with the theme's Preview link.
4. **Rollback:** publish the BACKUP copy (⋯ → Publish). This takes effect immediately.

## Shopify custom pixels (Settings → Customer events)

1. Before editing, copy the pixel's code into a text file named with the date.
2. **Rollback:** paste the saved code back and click **Save**, or disconnect the pixel.

## Google Ads

1. Before a change, record the current value in ADS-CHANGES-FOR-REVIEW.md (budget, bidding, goal, CPC cap, audience).
2. After the change, record the time (Europe/London).
3. **Rollback:** set the recorded values back. Tools → Change history shows every edit, and many single changes can be undone there.

## Pages (UK landing page)

Create it as a **hidden/draft page**. Rollback = keep it hidden or delete the draft. The live homepage stays untouched, including the India offers.
